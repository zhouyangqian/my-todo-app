# Feature Specification: 财务模块

**Feature Branch**: `007-finance-module`
**Created**: 2026-04-07
**Status**: Draft
**Input**: User description: "财务模块：账单管理/应收应付、收支记录、财务报表（资产负债表、利润表、现金流量表）、成本核算、发票管理、银行对账、预算管理、与进销存模块的结算集成、毛利计算"

## Clarifications

### Session 2026-04-07

- Q: 与进销存模块的集成方式？ → A: 自动同步 - 采购入库自动生成应付账款，销售出库自动生成应收账款，支持手动调整
- Q: 成本核算方法？ → A: 多种成本法 - 支持先进先出(FIFO)、加权平均、个别计价法，可按商品类别设置不同方法
- Q: 财务报表的生成周期？ → A: 实时+定期 - 支持实时查看，同时支持按月/季/年生成正式报表
- Q: 多币种支持？ → A: 支持 - 支持多币种记账，自动汇率转换，本位币报表
- Q: 预算控制的严格程度？ → A: 分级控制 - 可设置为强制控制（超预算禁止）、提醒控制（超预算警告）、仅记录（不控制）
- Q: 发票与账单的关联？ → A: 多对多 - 一张发票可关联多笔账单，一笔账单可分多张发票

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 应收应付管理 (Priority: P1)

系统能够完整管理企业的应收账款和应付账款，支持从进销存模块自动生成账单，以及手动创建账单，实现账款的全程跟踪和管理。

**Why this priority**: 应收应付是企业财务管理的核心，没有账款管理就无法掌握企业资金状况，直接影响现金流和经营决策。这是P1优先级的基础功能。

**Independent Test**: 可以独立测试应收应付账单的完整生命周期：创建账单 → 账单审核 → 收款/付款 → 账单核销 → 查看账款余额。

**Acceptance Scenarios**:

1. **Given** 销售订单完成出库，**When** 系统自动生成应收账款，**Then** 创建应收账单记录，关联销售订单，状态为"待收款"，金额等于销售金额
2. **Given** 采购订单完成入库，**When** 系统自动生成应付账款，**Then** 创建应付账单记录，关联采购订单，状态为"待付款"，金额等于采购金额
3. **Given** 财务人员手动创建应收账单，**When** 填写客户、金额、到期日等信息，**Then** 账单创建成功，状态为"待审核"
4. **Given** 账单待审核，**When** 审批人审核通过，**Then** 账单状态变更为"待收款/待付款"，可进行后续收款/付款操作
5. **Given** 客户支付货款，**When** 财务人员录入收款记录（金额、收款方式、收款账户），**Then** 系统自动核销对应账单，更新账款余额
6. **Given** 账单已部分收款，**When** 查看账单详情，**Then** 显示已收金额、未收金额、收款记录列表
7. **Given** 多笔应收账单待收款，**When** 收到一笔款项需要拆分核销，**Then** 支持按比例或指定金额分配到多笔账单

### User Story 2 - 收支记录管理 (Priority: P1)

系统能够记录和管理企业所有的收入和支出，包括经营性收支和非经营性收支，支持多账户管理，实现资金流向的完整记录。

**Why this priority**: 收支记录是财务数据的基础，没有收支记录就无法生成准确的财务报表和资金分析。这是P1优先级的基础功能。

**Independent Test**: 可以独立测试收支记录的增删改查，以及按账户、类别、时间范围的统计查询。

**Acceptance Scenarios**:

1. **Given** 财务人员记录一笔收入，**When** 填写收入类型、金额、收款账户、日期、备注，**Then** 收入记录创建成功，账户余额自动增加
2. **Given** 财务人员记录一笔支出，**When** 填写支出类型、金额、付款账户、日期、备注，**Then** 支出记录创建成功，账户余额自动减少
3. **Given** 需要在账户间转账，**When** 创建转账记录（转出账户、转入账户、金额），**Then** 同时生成一笔支出和一笔收入记录，更新两个账户余额
4. **Given** 查询收支记录，**When** 按时间范围、收支类型、账户筛选，**Then** 返回符合条件的记录列表，支持导出Excel
5. **Given** 需要修改已录入的收支记录，**When** 财务人员编辑记录，**Then** 系统记录修改日志，更新账户余额
6. **Given** 收支记录录入错误，**When** 删除记录，**Then** 系统标记为已删除（软删除），恢复账户余额

---

### User Story 3 - 发票管理 (Priority: P1)

系统能够管理销售发票和采购发票，支持发票的开具、接收、核销和统计，实现发票与账单的关联管理。

**Why this priority**: 发票是企业税务管理和财务合规的重要组成部分，直接影响税务申报和财务审计。这是P1优先级的合规功能。

**Independent Test**: 可以独立测试发票的开具、与账单关联、发票查询和统计功能。

**Acceptance Scenarios**:

1. **Given** 销售账单需要开票，**When** 财务人员创建销售发票（发票号、类型、金额、税率），**Then** 发票创建成功，可关联多笔应收账单
2. **Given** 收到供应商发票，**When** 财务人员录入采购发票信息，**Then** 发票记录创建成功，可关联多笔应付账单
3. **Given** 发票需要与账单关联，**When** 选择要关联的账单，**Then** 建立发票与账单的多对多关系，更新账单的开票状态
4. **Given** 查询发票，**When** 按发票类型、日期范围、开票状态筛选，**Then** 返回符合条件的发票列表
5. **Given** 需要统计开票情况，**When** 查看发票统计报表，**Then** 显示已开票金额、未开票金额、发票税率分布
6. **Given** 发票作废，**When** 财务人员标记发票作废，**Then** 发票状态更新，解除与账单的关联

---

### User Story 4 - 成本核算与毛利计算 (Priority: P1)

系统能够对商品成本进行核算，支持多种成本计算方法，自动计算销售毛利和毛利率，为经营决策提供数据支持。

**Why this priority**: 成本核算和毛利分析是企业盈利能力分析的核心，直接影响定价策略和经营决策。这是P1优先级的分析功能。

**Independent Test**: 可以独立测试成本核算方法设置、成本计算、毛利报表生成功能。

**Acceptance Scenarios**:

1. **Given** 系统管理员设置成本核算方法，**When** 按商品类别选择成本方法（FIFO/加权平均/个别计价），**Then** 保存设置，后续成本计算按此方法执行
2. **Given** 采用加权平均法，**When** 新采购入库产生新的采购成本，**Then** 系统自动重新计算该商品的加权平均成本
3. **Given** 销售出库发生，**When** 系统计算销售成本，**Then** 根据设置的成本方法计算本次销售的成本金额
4. **Given** 销售完成，**When** 查看销售毛利，**Then** 显示销售收入、销售成本、毛利、毛利率
5. **Given** 需要分析商品毛利，**When** 查看毛利分析报表，**Then** 按商品、类别、时间段展示毛利和毛利率排名
6. **Given** 需要调整历史成本，**When** 财务人员进行成本调整（录入调整金额和原因），**Then** 更新商品成本，记录调整日志

---

### User Story 5 - 银行对账 (Priority: P2)

系统能够导入银行流水，与系统收支记录进行对账，自动或手动匹配，识别未达账项，确保账实相符。

**Why this priority**: 银行对账是确保财务数据准确性的重要手段，但可以依靠人工核对，优先级为P2。

**Independent Test**: 可以独立测试银行流水导入、自动匹配、手动对账、对账报表生成功能。

**Acceptance Scenarios**:

1. **Given** 财务人员导入银行流水，**When** 上传银行对账单文件（支持Excel/CSV），**Then** 系统解析文件，创建银行流水记录
2. **Given** 银行流水已导入，**When** 系统执行自动对账，**Then** 根据金额、日期、摘要自动匹配系统收支记录
3. **Given** 自动匹配不完整，**When** 财务人员手动对账，**Then** 可手动选择银行流水与系统记录进行关联
4. **Given** 对账完成，**When** 查看对账报表，**Then** 显示已对账记录、未对账记录、未达账项列表
5. **Given** 发现银行流水错误，**When** 标记为异常流水，**Then** 记录异常原因，不参与对账
6. **Given** 银行账户余额，**When** 与系统账户余额对比，**Then** 显示差异金额和差异原因分析

---

### User Story 6 - 预算管理 (Priority: P2)

系统能够设置和管理企业预算，包括收入预算、支出预算，支持预算编制、执行跟踪、预算预警和预算分析。

**Why this priority**: 预算管理有助于企业控制成本和规划资金，但属于管理增强功能，优先级为P2。

**Independent Test**: 可以独立测试预算编制、预算执行跟踪、预算预警功能。

**Acceptance Scenarios**:

1. **Given** 财务人员编制年度预算，**When** 按部门、科目、时间段设置预算金额，**Then** 保存预算方案，状态为"待审批"
2. **Given** 预算方案待审批，**When** 审批人审核通过，**Then** 预算方案生效，开始执行跟踪
3. **Given** 预算执行中，**When** 发生收支记录，**Then** 系统自动更新预算执行进度
4. **Given** 预算即将超支，**When** 执行进度达到预警阈值（如80%），**Then** 系统发送预警通知给相关人员
5. **Given** 预算控制为强制模式，**When** 支出申请超过剩余预算，**Then** 系统拒绝支出申请，提示预算不足
6. **Given** 需要调整预算，**When** 财务人员提交预算调整申请，**Then** 记录调整原因和金额，需审批后生效
7. **Given** 查看预算执行情况，**When** 查看预算分析报表，**Then** 显示各科目预算金额、已执行金额、执行率、预计完成情况

---

### User Story 7 - 财务报表生成 (Priority: P1)

系统能够自动生成标准的财务报表，包括资产负债表、利润表、现金流量表，支持多维度查询和导出。

**Why this priority**: 财务报表是企业财务状况和经营成果的综合反映，是财务管理的核心输出，优先级为P1。

**Independent Test**: 可以独立测试财务报表的数据汇总、报表生成、报表查询和导出功能。

**Acceptance Scenarios**:

1. **Given** 需要查看资产负债表，**When** 选择报表日期，**Then** 系统汇总资产、负债、所有者权益数据，生成资产负债表
2. **Given** 需要查看利润表，**When** 选择时间范围，**Then** 系统汇总收入、成本、费用数据，计算利润，生成利润表
3. **Given** 需要查看现金流量表，**When** 选择时间范围，**Then** 系统按经营、投资、筹资活动分类汇总现金流，生成现金流量表
4. **Given** 报表需要导出，**When** 选择导出格式（Excel/PDF），**Then** 生成对应格式的报表文件
5. **Given** 需要对比分析，**When** 选择多个时间段，**Then** 生成同期对比报表，显示增减变动
6. **Given** 多币种业务，**When** 选择币种，**Then** 报表按指定币种展示（自动汇率转换）
7. **Given** 需要保存报表快照，**When** 生成正式报表并锁定，**Then** 报表数据不可修改，作为历史记录保存

---

### User Story 8 - 进销存结算集成 (Priority: P1)

财务模块与进销存模块深度集成，实现采购结算、销售结算、库存成本核算的自动化处理。

**Why this priority**: 财务与业务的一体化是企业信息化的核心需求，自动集成可大幅提高效率和准确性。优先级为P1。

**Independent Test**: 可以通过完整的业务流程测试集成：采购入库 → 应付生成 → 付款 → 成本计算；销售出库 → 应收生成 → 收款 → 毛利计算。

**Acceptance Scenarios**:

1. **Given** 采购入库单审核通过，**When** 系统自动生成应付账单，**Then** 账单金额等于入库金额，关联入库单，支持手动调整
2. **Given** 销售出库单审核通过，**When** 系统自动生成应收账单和销售收入，**Then** 同时计算销售成本和毛利
3. **Given** 采购退货发生，**When** 退货单审核通过，**Then** 自动生成红字应付账单，冲减原应付金额
4. **Given** 销售退货发生，**When** 退货单审核通过，**Then** 自动生成红字应收账单和红字收入，冲减原应收和收入
5. **Given** 库存盘点调整，**When** 盘点差异确认，**Then** 自动生成盘盈盘亏的收支记录，调整库存成本
6. **Given** 查看结算明细，**When** 查看某笔业务的财务关联，**Then** 显示业务单据 → 账单 → 收付款 → 发票的完整链路

## Non-Functional Requirements *(mandatory)*

### Performance

- 财务报表生成时间：月度报表 ≤ 10秒，年度报表 ≤ 30秒
- 支持10万级账单数据的查询响应时间 ≤ 3秒
- 支持100万级收支明细的存储和查询

### Security

- 所有财务数据变更必须记录审计日志
- 敏感财务数据（金额、账户）需要加密存储
- 支持财务数据的访问权限控制（按角色、按部门）
- 关键财务操作（报表锁定、账单作废）需要二次确认

### Reliability

- 财务数据变更支持回滚机制
- 报表数据生成后支持版本管理和历史追溯
- 系统支持财务数据的每日自动备份

### Compatibility

- 支持主流银行对账单格式导入
- 支持导出符合财务软件标准的数据格式
- 支持多币种、多税率的财务处理

---

## Out of Scope

- 税务申报表的自动生成（需与税务系统集成）
- 在线支付网关的直接对接（由网关模块处理）
- 复杂的财务预测和AI分析
- 多公司合并报表（企业版功能）
