## Acceptance Criteria Status

### US1 - 应收应付管理
- [ ] 自动生成应收账款（销售出库）
- [ ] 自动生成应付账款（采购入库）
- [ ] 手动创建账单
- [ ] 账单审核流程
- [ ] 收款/付款记录
- [ ] 部分收款/付款
- [ ] 多账单拆分核销

### US2 - 收支记录管理
- [ ] 收入记录创建
- [ ] 支出记录创建
- [ ] 账户间转账
- [ ] 多条件筛选查询
- [ ] 记录修改和日志
- [ ] 记录删除（软删除）

### US3 - 发票管理
- [ ] 销售发票创建
- [ ] 采购发票录入

- [ ] 发票查询
- [ ] 发票统计
- [ ] 发票作废

### US4 - 成本核算与毛利计算
- [ ] 成本核算方法设置

- [ ] 成本调整

### US5 - 银行对账
- [ ] 银行流水导入
- [ ] 自动对账匹配
- [ ] 手动对账
- [ ] 对账报表
- [ ] 异常流水标记
- [ ] 余额差异分析

### US6 - 预算管理
- [ ] 预算编制

### US7 - 财务报表生成
- [ ] 资产负债表

- [ ] 报表导出（Excel/PDF）

### US8 - 进销存结算集成
- [ ] 采购入库→应付账单
- [ ] 销售出库→应收账单+收入+成本
- [ ] 采购退货→红字应付
- [ ] 销售退货→红字应收+红字收入
- [ ] 库存盘点→盘盈盘亏记录
- [ ] 结算链路追溯
